# Asset: 6080017

## Description
Prototype test firmware for the XIAO nRF52840 Sense: a hardware bring-up sketch (steps each LED, samples the LDR, reads battery voltage — run before trusting any soldered joint) and a Meadow + courtship demo implementing the sequence from [DevNote 6080015](./DevNote-Courtship-Sequence.md), the model [DD-9's 2026-10-12 addendum](../Design/DD-9-Glow-Pattern.md) reconciled on. Deliberately excludes IMU wake/sleep power management, the FR-2..FR-4 state machine, and the low-battery cue — see [Assembly.md's Test Code section](./Assembly.md#test-code) for what's in and out of scope and why.

## Revision
A: initial build — bring-up sketch; courtship demo (fixed a landing-position bug found while tracing the DevNote's pseudocode against its own worked example — see the sketch's header comment).
