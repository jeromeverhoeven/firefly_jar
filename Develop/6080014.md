# Asset: 6080014

## Description
Interactive visual timing bench ("Big Dipper Dialogue") for evaluating the firefly jar's flash pattern against *Photinus pyralis* field data — the male's J-shaped flash and dip/hook flight, the female's timed answer, and the dark intervals between. Includes a live oscilloscope view and a direct export to the firmware constants named in [Spec-2's Data Model](../Design/Spec-2.md#data-model-firmware-configuration) (`FLASH_PERIOD_S`, `FADE_MS`, `ANSWER_DELAY_MS`). Supports tuning [DD-9](../Design/DD-9-Glow-Pattern.md)'s glow-pattern parameters before they're committed to firmware.

Published artifact: https://claude.ai/code/artifact/f9e94bdf-678f-432e-8ac6-cef761c03a79

## Revision
- A: initial build — male/female flash envelopes, dip-and-hook flight path, homing/"locating" approach over cycles, oscilloscope with documented-range bands, temperature scaling (illustrative), firmware constant export.
- B: phone layout fix — taller square stage with playback controls moved below the jar at ≤680 px width (previously the controls covered the jar), canvas text/LEDs scaled for high-density screens, and the firmware code box no longer forces sideways scrolling.
